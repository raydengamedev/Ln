# Anime Season 1 Plan: *The Demon Lord's Accountant*

**Format:** 12 episodes × 12 minutes, delivered as MP4
**Source:** Light novel Volume 1, *Opening Balance* (Prologue, Chapters 1–10, Epilogue)
**Style:** Mostly motion comic (Live2D puppets plus layered art, with camera moves), with a few hand-animated or AI-assisted shots for the key action
**Season runtime:** about 144 minutes

---

## Delivery spec (every episode)

| Setting | Value |
|---|---|
| Container | MP4 |
| Resolution | 1920 × 1080 (16:9). 4K optional later. |
| Frame rate | 23.976 fps (anime standard) |
| Video codec | H.264 High profile, `yuv420p`, CRF 18–20 |
| Audio | AAC, 48 kHz stereo, 320 kbps |
| Loudness | −14 LUFS integrated, −1 dBTP peak (YouTube standard) |
| Subtitles | English `.srt` sidecar file, plus an optional burned-in version |
| Web optimisation | `+faststart`, so playback starts before the download finishes |
| Approx. file size | 400–700 MB per episode |

| Key illustrations | 10–20 | about 150–200 |
| Hand-animated or AI-assisted footage | 20–60 s | about 6–10 min |

**Reusable assets** (made once, used all season):
- **Live2D rigs:** Ren, Velzaria (majesty form), Velzaria (real form), Sileth, Grisla, Nib, and an ogre captain.
- **Secondary rigs or stills:** generals, the Grayhallow lawyer, the Notary, Hinata (a cameo), shopkeepers.
- **Locations:** throne room, treasury office, castle roof, supply depot, Coinmarch market, the villages, the Stone of Oaths, the mountain pass.
- **Audio:** the title sting, ending song, eyecatch jingle, character themes, and the [Double Entry] chime.

### Voice cast

| Role | Line share | Voice direction |
|---|---|---|
| Kurata Ren | about 35% | Dry, deadpan, quick. Comedy comes from understatement. |
| Velzaria | about 25% | **Two voices:** a regal, low register in majesty form, and her natural pitch in her real form, which cracks when flustered. Needs strong comic timing. |
| Sileth | about 10% | A silky, amused older-sister voice that drops into sincerity in Ep. 7. |
| Grisla | about 10% | Loud, blunt, gravelly. Goes surprisingly soft in the reading-lesson scenes. |
| Nib | about 8% | High-pitched and anxious, panicking about numbers. |
| Others | about 12% | Generals, ogres, the lawyer, the Notary, Hinata, narration cards. |

## Production pipeline (per episode)

1. **Script:** an anime-format script with line IDs (`E01_S03_L012`), shot cues and sound cues. *(I write this.)*
2. **Shot list:** for each shot, the framing, camera move, length, line IDs and assets needed, in a machine-readable file. *(I write this.)*
3. **Asset checklist:** generated automatically from the shot list: which art, voice lines and sound effects are needed, and which are missing.
4. **Voice recording:** a casting call and script sheets sent to the actors. Files come back named by line ID.
5. **Art:** backgrounds, key illustrations and Live2D puppet animation, exported as layers or clips.
6. **Animatic → final render:** a Python and ffmpeg pipeline in this repo takes the shot list, the art (or placeholders), the voice lines, sound effects and music, and outputs the episode MP4. It can render a placeholder animatic on day one and swap in finished art as it arrives.
7. **Mix and master:** dialogue, then music, then sound effects, normalised to −14 LUFS.
8. **Quality check:** a sync check, a subtitle check and a spec check with `ffprobe`, then release.

### Repo layout (proposed)

```
demon-lords-accountant/
  anime/
    bible/          art, voice and sound bibles
    scripts/        ep01.md … ep12.md
    shotlists/      ep01.yaml … ep12.yaml
    render/         the Python and ffmpeg render pipeline
    assets/         small placeholders only. Real media lives outside git (see below).
```

**Large media storage:** GitHub rejects files over 100 MB, and finished episodes are 400–700 MB. Art, audio and finished MP4s should go in Git LFS or cloud storage (Google Drive, Dropbox, S3). The repo keeps the scripts, shot lists and render pipeline.

## Novel and anime: which first?

- **Script-first (faster to video):** write the 12 episode scripts straight from the outline, then write the novel prose afterwards, using the scripts as a detailed outline.
- **Novel-first (the traditional route):** write Volume 1, then adapt it.
- **Recommendation:** script-first. Both formats share the same story and dialogue, and the scripts give the voice actors and artists something to work from sooner.

## Decisions that affect the scripts

1. **Content level:** this matters more for video. YouTube limits advertising on suggestive content and age-restricts explicit content.
2. **Voices:** human voice actors for the main cast (recommended), AI voices, or a mix?
3. **The harem ending:** monogamous, or a harem ending? This affects the Season 1 setup lightly and the later seasons heavily.
4. **Who makes the art:** a commissioned artist plus a Live2D rigger, AI-generated art, or a mix?
